# assets/

Generated from the Perfect Dark decomp by `tools/pd-assets/` and committed. Do not edit by hand: change the exporter and rerun `python tools/pd-assets/build_assets.py`. The layout, keyed by PD's own ids, is specified in [docs/ARCHITECTURE.md § Assets](../docs/ARCHITECTURE.md#assets). `MANIFEST.json` records what generated each file.

The game finds this directory at run time through `PD_ASSETS`, or by walking up from the executable.

Empty until M1.
